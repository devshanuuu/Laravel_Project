A simple CRUD (Create, Read, Update, Delete) application built with Laravel. This project was created to learn the fundamentals of Laravel, including routing, controllers, models, migrations, Blade templates, form handling, validation, and Bootstrap.

## Features

- Add a new student
- View all students
- Edit student details
- Delete a student
- Form validation
- Validation error messages
- Success messages after Create, Update, and Delete
- Responsive Bootstrap UI

## Technologies Used

- Laravel
- PHP
- MySQL
- Blade Template Engine
- Bootstrap 5
- HTML
- CSS

## Project Structure

- **Routes** - Handles application URLs
- **Controllers** - Contains application logic
- **Models** - Interacts with the database using Eloquent ORM
- **Migrations** - Creates and manages database tables
- **Blade Views** - Displays the frontend UI
